# Олон хэл (i18n) — Mongolian / English

Web app нь `react-i18next` дээр суурилсан. Анхдагч хэл нь **монгол** (`mn`),
English (`en`) нь нэмэлт. Хэрэглэгч AppShell болон Login дээрх **MN / EN**
товчоор сольдог; сонголт `localStorage` (`fleex.lang`)-д хадгалагдаж `<html lang>`
автоматаар шинэчлэгдэнэ.

## Бүтэц

```
src/i18n/
  index.ts            # i18next init (mn + en, fallback=mn, lang persistence)
  locales/mn.json     # монгол текст (эх хэл)
  locales/en.json     # English текст
```

- `src/main.tsx` нь `import './i18n'` хийж render-ээс өмнө эхлүүлдэг.
- Дутуу түлхүүр байвал `mn` руу fallback хийнэ.

## Хуудас шилжүүлэх загвар

1. Дээд талд:
   ```tsx
   import { useTranslation } from 'react-i18next';
   ```
2. Компонент дотор:
   ```tsx
   const { t } = useTranslation();
   ```
3. Хатуу бичсэн текстийг `t()`-ээр солих:
   ```tsx
   // өмнө:  <h1>Хяналтын самбар</h1>
   // дараа: <h1>{t('dashboard.title')}</h1>
   ```
4. Түлхүүрийг **mn.json ба en.json хоёуланд** нэмэх. Namespace нь хуудас тус
   бүрээр (`dashboard.*`, `devices.*`, `events.*` …). Нийтлэг үг `common.*`,
   цэс `nav.*`, role `role.*`-д аль хэдийн бий.
5. Interpolation:
   ```tsx
   t('devices.count', { n: devices.length })   // "{{n}} төхөөрөмж"
   ```
6. Module-level массив дахь текстийг (жишээ нь AppShell-ийн SECTIONS) **түлхүүр**
   болгож хадгалаад render үед `t(key)` дуудна (`t()` нь компонент дотор л
   ажиллана).

## Төлөв

| Хэсэг | Төлөв |
|---|---|
| i18n суурь + хэл солих товч + persistence | ✅ |
| AppShell (цэс, section, role, logout) | ✅ |
| Login | ✅ |
| Бусад 25 хуудас (Dashboard, Devices, Drivers, Events, Reports, …) | ⏳ үе шаттай |

## Үлдсэн ажил (хуудас бүрд)

Хуудас тус бүрийн хатуу монгол текстийг дээрх загвараар `t()` болгож, `mn.json`
+ `en.json`-д түлхүүр нэмнэ. Тэргүүлэх дараалал (харагдац өндөр):
Dashboard → Devices → LiveMap → Events → Reports → Drivers → бусад.

> **Зөвлөмж:** API-аас ирдэг текст (event type label, role нэр гэх мэт) зарим нь
> server талд монголоор бэлдэгддэг. Тэдгээрийг бүрэн орчуулахын тулд server нь
> код (enum) буцааж, нэрийг client `t()`-ээр шийдэх (эсвэл `Accept-Language`
> дэмжих) болгох нь дараагийн алхам.
