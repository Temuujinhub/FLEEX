Энэхүү баримт нь бүхэл системд (Go gps-ingestor, Go events-engine, NestJS API,

хэрэгжүүлсэн засваруудыг нэгтгэнэ. Бүх илрэлийг кодоос биечлэн баталгаажуулсан.

## 0. Нэгдсэн үнэлгээ

Fleex бол **боловсорсон, сайн архитектуртай** mining-grade GPS fleet-tracking
SaaS (~26K мөр). Бараг бүх дэлгэц жинхэнэ API-тай холбогдсон, ажилладаг.
Аюулгүй байдлын суурь сайн: Argon2id, refresh-token rotation + reuse
detection, hash-chain audit (advisory-lock-аар цувуулсан), multi-tenant
isolation голдуу зөв, SQL injection алга, CI-д host-key pinning.

Гэвч аудит нь **1 critical privilege escalation**, **1 critical remote DoS**,
deploy бүрт өгөгдөл алдагдах reliability bug, болон бараг тэг тест зэрэг
ноцтой зүйлсийг илрүүлэв. Тэдгээрийн ихэнхийг энэ branch дээр засав.

## 1. Cybersecurity

### CRITICAL

| # | Илрэл | Файл | Төлөв |
|---|---|---|---|
| C-1 | **Privilege escalation:** COMPANY_ADMIN `POST /api/users {role:"SUPER_ADMIN"}` дуудаж бүх tenant эзэмдэнэ. `create()`-д role-ladder шалгалт байгаагүй (`update()`-д байсан). | `users.service.ts` | ✅ |
| C-2 | **Алсын DoS:** `dataLen==1` бүхий Teltonika пакет `payload[1]`-д panic → recover байхгүй тул бүх ingestor унаж 1000 төхөөрөмж тасарна. Auth шаардахгүй. | `teltonika/codec.go`, `cmd/ingestor/main.go` | ✅ |

**C-1 засвар:** `create()`-д `if (rank(dto.role) > rank(actor.role)) throw` нэмэв.
**C-2 засвар:** `dataLen >= 3` шаардав + `handle()`/`runCommandLoop()`-д
`recover()`. Регресс тест нэмэв (`codec_test.go`).

## 4. Гадаад системтэй харьцуулсан зөрүү (Wialon/Traccar/Navixy/Samsara)

Fleex-д аль хэдийн **маш баялаг** функц (live map, history, geofence
өдөр/шөнө хурд, events, trips, eco/scorecard, sensor calibration, device
health, олон сувгийн notification, places, reports + idle-billing, Codec-12
commands, hash-chain audit, multi-tenant RBAC, support tickets, service
tasks + predictive, GPRS counters, dispatcher board, OBD/CAN decode).

**Стратегийн зөрүү (эрэмбээр):**
1. **Multi-protocol дэмжлэг** (#1) — зөвхөн Teltonika. → `MULTI-PROTOCOL-DESIGN.md`.
2. Public API + API keys + webhooks ⏸ (хэрэглэгчийн хүсэлтээр хойшлуулав).
3. 2FA/MFA (schema-д багана байгаа) + SSO.
4. Түлшний аналитик (refuel/drain/theft, Fuel report одоо "Удахгүй").
5. Видео телематик (MDVR) — rig байгаа ч бүтээгдэхүүн болоогүй.
6. HA / multi-region + PITR backup (одоо single host).
7. Mobile/PWA driver app; route/dispatch optimization; scheduled/custom reports.
8. i18n (en/ru) ⏸ (хэрэглэгчийн хүсэлтээр хойшлуулав).
